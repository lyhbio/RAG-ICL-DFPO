# DMCR Correction and Evaluation

This folder contains the DMCR correction/evaluation scripts.

## What This Folder Does

- Reads raw ICL JSON files generated by the no-DMCR script.
- Applies DMCR correction to malformed string outputs.
- Writes `fix_<raw>.json`.
- Computes raw and fixed Precision/Recall/F1.
- Can redraw the before/after DMCR figures from raw/fix RAG-ICL result files.

## Files

- `scripts/reproduce_icl_dmcr_eval.py`
  - Input: one raw JSON file.
  - Output: fixed JSON and raw/fixed metrics TSV.
- `scripts/plot_dmcr_raw_vs_fix.py`
  - Redraws the DMCR raw-vs-fix multi-panel figures.
- `requirements.txt`
  - Minimal Python dependencies for correction/evaluation.

## Data Layout

For metric calculation, the script expects:

```text
<data-root>/
  <dataset>/
    Data/test_data/*.json
```

For figure reproduction, `plot_dmcr_raw_vs_fix.py` currently reads the original
RAG-ICL raw/fix files from:

```text
/mnt/disk1/wanghongyin/work/Paper_Evaluate_Pipeline/RAG-ICL_OriginResults_Logs/RAG-ICL
```

If packaging this on GitHub, either preserve the same internal data layout or
edit `PIPELINE_ROOT` / `RAG_SOURCE_ROOT` in the plotting script.

## Example

```bash
python scripts/reproduce_icl_dmcr_eval.py \
  --data-root /path/to/Paper_Evaluate_Pipeline/code \
  --dataset NCBI_Disease \
  --task-type disease \
  --raw-json outputs/icl_raw/NCBI_Disease/qwen2/FERS/1_samples/1.json \
  --dmcr-model gemma2:9b \
  --ollama-host http://127.0.0.1:11435
```

Redraw all DMCR figures:

```bash
python scripts/plot_dmcr_raw_vs_fix.py --all
```

## Notes

DMCR uses an evaluator LLM, defaulting to `gemma2:9b`, to convert malformed
string outputs into the expected Python-list format. The original raw JSON is
not overwritten; corrected output is written as `fix_<raw>.json`.
